# Michael Seifert Portfolio

Personal portfolio website for me.

## Features
- Two-column layout with a sticky sidebar and scrolling content
- Light/dark theme toggle with preference saved in localStorage
- Smooth anchor navigation and skip-link accessibility
- Projects, skills, and contact sections with social links

## Customize
- Update text content in `portfolio/index.html` (name, role, about, contact)
- Add or edit projects in the Projects section
- Adjust theme colors in `styles/styles.css` under `.light` and `.dark`
- Replace social links in the sidebar footer
